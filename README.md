# mc1r-canideos-alinhamento
Análise do gene melanocortin 1 receptor (MC1R) em canídeos com Python
## Objetivo
O projeto visa alinhar o gene MC1R do cão doméstico, dingo e lobo mexicano.
## Método
Ao alinhar, é possível comparar os nucleotídeos e checar a conservação do gene
Para rodar os dados, se utiliza o software Clustal Omega e assim encontrar os SNPs.
## Dados
A base de dados utilizada é o National Center of Biotechnology Information (NCBI).
